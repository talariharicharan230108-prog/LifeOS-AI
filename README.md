# LifeOS – AI Personal Life & Study Assistant
**Fundamentals of Artificial Intelligence (Year 2 Term 1 Project)**

LifeOS is an AI-powered personal productivity portal designed specifically for university students. It combines real local data management (academic courses, tasks, weekly planning, exams, goals, and uploaded course materials) with Google Gemini AI agent reasoning, autonomous tool execution, and clear practical demonstrations of the Fundamentals of Artificial Intelligence syllabus (Modules I through X).

---

## 🚀 Key Features

1. **AI Agent (`/agent`)**:
   - Conversational assistant powered by Google Gemini API.
   - Operates on real user context (tasks, subjects, deadlines, daily routine).
   - Autonomous tool calling: `add_task`, `update_task`, `delete_task`, `create_schedule`, `get_tasks`, `get_schedule`.
   - Complete **Transparency Pipeline**: User Request → Understand → Retrieve Context → Gemini Reasoning → Tool Execution → Final Output.
   - Built-in zero-hallucination policy (Module VIII): Explicitly reports lack of information when data is unrecorded.

2. **Smart Dashboard (`/dashboard`)**:
   - Real-time morning briefing generated by Gemini based on stored user data.
   - One-click **"Create Today's Plan"** utilizing state space constraint satisfaction.
   - Live KPI metrics: Completed Tasks, Pending Tasks, Today's Schedule, Upcoming Deadlines, Syllabus Progress, Tracked Goals.

3. **Task Management (`/tasks`)**:
   - Full CRUD operations with priority tags (`high`, `medium`, `low`), deadlines, and subject categories.
   - Filter by All, Pending, Completed, or High Priority; sort by closest deadline or priority.

4. **Weekly Planner & Master Calendar (`/planner`, `/calendar`)**:
   - Unified storage between tasks, study sessions, and events.
   - 7-day Monday–Sunday visual columns with scheduled time blocks.
   - Interactive month calendar view with day-specific deadline indicators and event creation.

5. **Academic Hub (`/academic`)**:
   - Manage real courses (teacher, credits, syllabus progress bar, key topics, exam countdowns).

6. **Documents & Simple RAG (`/documents`)**:
   - Upload course materials (PDF, TXT, DOCX) with text extraction.
   - Ask semantic questions (*"Summarize this document"*, *"What are the important topics?"*, *"Generate 5 exam questions"*).

7. **Goals & Milestones (`/goals`)**:
   - Track academic, career, and personal targets with interactive progress controls.

8. **AI Concepts Laboratory (`/concepts`)**:
   - Interactive 7x7 grid search visualizer for **BFS, UCS, DLS, Greedy Best-First, and A\* Search** (Modules II & III).
   - Live forward-chaining rule engine (Module V).
   - State space constraint satisfaction planner visualizer (Modules IV & VII).
   - Knowledge ontology and learning agent progress tracking (Modules VI, IX, X).

## 🛠️ Installation & Setup

### 1. Backend Setup (FastAPI & Python 3.10+)

```powershell
cd backend
python -m pip install -r requirements.txt
```

### 2. Configure Gemini API Key

Open `backend/.env` and insert your Gemini API Key:
```env
GEMINI_API_KEY=AIzaSy...YourKeyHere
PORT=8000
HOST=127.0.0.1
GEMINI_MODEL=gemini-2.5-flash
GEMINI_FALLBACK_MODELS=gemini-2.5-flash-lite,gemini-3.8-flash,gemini-3.5-flash,gemini-flash-latest
```
*(Alternatively, you can launch the app and enter your key directly inside **Settings → Gemini AI Settings**, which updates `.env` securely. LifeOS automatically switches between models if a model is unavailable or rate-limited).*

### 3. Frontend Setup (React + Vite)

```powershell
cd ../frontend
npm install
```

## 🏃 Running the Application

### Start Backend Server:
```powershell
cd backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

### Start Frontend Dev Server:
```powershell
cd frontend
npm run dev
```

Open your browser to: **`http://localhost:5173`**

## 🧠 Implemented AI Syllabus Concepts (Modules I – X)

| Module | Syllabus Topic | Implementation in LifeOS |
|---|---|---|
| **Module I** | LLMs, Prompting & APIs | Google Gemini API integration with structured JSON prompting, fallback handling, and connection validation in `backend/app/gemini.py`. |
| **Module II** | Uninformed Search | Interactive visualizer on `/concepts` page implementing **BFS**, **Uniform Cost Search (UCS)**, and **Depth Limited Search (DLS)**. |
| **Module III** | Informed Search | Interactive visualizer on `/concepts` page implementing **Greedy Best-First Search** and **A\* Search** with Manhattan heuristic $f(n) = g(n) + h(n)$. |
| **Module IV** | Optimal Decisions & Planning | LifeOS planning agent factors in deadlines, priority weights, and time constraints to generate optimal daily schedules. |
| **Module V** | Rule-Based Inference | Forward-chaining rule engine evaluating conditions (e.g. `IF deadline <= 1 day AND priority == HIGH THEN Recommend "Complete first"`). |
| **Module VI** | Knowledge Representation | Structured ontology representing entities: `User`, `Routine`, `Subject`, `Task`, `Goal`, `Event`, and `Document`. |
| **Module VII** | State Space Planning | Transforms Initial State $S_0$ (pending tasks) through Constraints $C$ (college hours, sleep window) into Goal State $S^*$ (non-conflicting schedule). |
| **Module VIII** | Uncertainty Management | Zero-hallucination policy: when user asks about missing or uncertain data, agent strictly replies *"I don't have enough information to determine this."* |
| **Module IX** | Learning Agents | Observes completion vs. backlog history to adaptively recommend schedule buffer adjustments. |
| **Module X** | Applications of AI | Practical deployment of AI across university student education, time management, and document comprehension. |

## 🧪 Testing the AI Agent

1. Launch `http://localhost:5173`.
2. Complete the onboarding wizard (Name, College, Routine, initial subjects).
3. Open **AI Agent** from the sidebar.
4. Try asking:
   - *"What should I do today?"* → Reads pending tasks and inference alerts.
   - *"Add task Submit FAI Term Project due 2026-10-15 priority high"* → Autonomous tool execution (`add_task`).
   - *"Create my plan for today"* → Generates structured schedule blocks taking college hours into account.
   - *"What should I study today?"* → Analyzes subject credits and upcoming exam deadlines.
5. In **Documents**, upload a sample lecture or syllabus file (`.txt`, `.pdf`, `.docx`) and ask:
   - *"Summarize this document."*
   - *"What are the important topics covered?"*
